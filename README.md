# Roll-a-Ball-2026
Projeto Roll a Ball feito como atividade avaliativa para a matéria Programação de Jogos do curso de Jogos Digitais da UNEB, campus Salvador, no semestre letivo de 2026.2. O projeto foi realizado na versão do Unity 6.0 (6000.0.82f1).
Este é um projeto Roll a Ball no qual foram utilizados assets gratuitos obtidos através do site da Asset Store da Unity, com assets especificamente para a aparência e textura para a bola de espinhos controlada pelo jogador, das bombas para os itens coletáveis, de paredes de blocos de cimento e de tijolos para as paredes da arena e chão dela.

Neste projeto os objetos coletáveis estão espalhados ao longo de corredores de labirintos projetados no mapa de jogo, para criar um pequeno desafio de rapidez e controle preciso da bola de espinhos pelo jogador, além de trazer o objetivo de navegação através do labirinto para tornar a jogabilidade um pouco mais interessante em face do objetivo de coletar as bombas.

Através desta personalização buscou-se trazer uma similaridade com jogos antigos da franquia _Super Bomberman_, com a diferença de que o jogador não utiliza bombas para destruir os objetos e obstáculos no cenário, mas deve coletá-las para cumprir a condição de vitória do jogo.
